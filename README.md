# 상상부기 키우기

출석과 과제 같은 학사 정보와 연동해 캐릭터를 키우고 방을 꾸미는 모바일 게임입니다.
한성대학교 캡스톤디자인 4인 팀 프로젝트(2026년 1월~6월)로 만들었고, 6월 교내 전시에서 시연했습니다.

> **개발 내역은 [`Integrated-Feature`](https://github.com/DOHA1012/SSBG_SIM/tree/Integrated-Feature) 브랜치에 있습니다.**
> `main`에는 프로젝트를 처음 만들 때의 커밋만 있습니다.

## 구성

| 구분 | 내용 |
|---|---|
| 클라이언트 (이 저장소) | 언리얼 엔진 5.7, 세로 화면 모바일. 블루프린트 중심, 일부 C++ |
| 서버 | 게임 서버, 가상 학사 서버, 운영 어드민 — [SSBG_SIM_Server](https://github.com/dragove267-oss/SSBG_SIM_Server) |
| API | 게임 API 36개 |

시연 때는 서버를 오라클 클라우드에서 운영했고, 지금은 인스턴스를 반납해 로컬에서만 실행됩니다.

## 게임 구조

- **하루 단위 코어 루프** — 학사 데이터 정산, 보상 지급, 상점 갱신, 꾸미기로 이어집니다.
- **재화 3종 조합** — 조합에 재화 세 가지를 모두 요구해, 출석만으로는 아무것도 만들 수 없게 했습니다.
- **방 꾸미기** — 가구마다 방 안의 배치 지점을 정해 장착하면 그 자리에 놓이고, 방이 채워진 정도가 곧 성장 단계로 보이게 했습니다.

## 맡은 일

팀장이자 유일한 기획자로 기획 전반과 수치 설계, 일정 관리를 맡았습니다.
게임 API의 구조를 정의해 구현을 요청하고 모두 직접 호출해 검수했으며, 서버 3종을 클라우드에 배포하고 운영 어드민을 구축했습니다.
클라이언트에서는 블루프린트로 화면 전환 처리를 맡았습니다.
